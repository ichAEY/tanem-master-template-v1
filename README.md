# TANEM Master Template v1

Единый производственный шаблон для новых сайтов мастеров TANEM.

## Идея

Этот репозиторий не является сайтом конкретного мастера. Он хранит только структуру, правила наполнения и сборку. Новый клиент создаётся копированием этого репозитория, после чего меняются данные в `site-data.mjs` и добавляются фотографии в `assets/images/`.

Базовый визуальный шаблон зафиксирован на версии `ichAEY/claytone-current` commit `ce1bd42b44e76e1851af9e069c4cbcf06fc8eac2`. Поверх него применяется универсальный TANEM patch.

## Что меняется для нового клиента

1. `site-data.mjs` — все данные мастера, услуги, цены, ссылки, отзывы, SEO, акции.
2. `assets/images/logo.jpg` — логотип, если есть.
3. `assets/images/master.jpg` — фотография мастера.
4. `assets/images/portfolio/01.jpg`, `02.jpg` и далее — портфолио.
5. `.github/workflows/pages.yml` — при необходимости меняется только `SITE_BASE_PATH` для собственного домена.

## Фиксированная структура

- Нет блока «до / после».
- Портфолио: 5 работ в превью; две нижние фотографии идут перед кнопкой открытия полной галереи.
- Все основные мобильные кнопки имеют tactile/active-состояния.
- Акции показываются только если `promotions` не пустой.
- Есть два режима услуг:
  - `simple` — обычные 2 направления;
  - `categories` — несколько самостоятельных направлений с горизонтальной лентой категорий на мобильном.
- Архитектура и дизайн не меняются под клиента без прямого решения изменить сам TANEM Master Template.

## Изображения

В шаблоне нет клиентских фотографий. Папки сохранены через `.gitkeep`.

```text
assets/
  images/
    logo.jpg
    master.jpg
    portfolio/
      01.jpg
      02.jpg
      ...
```

## Новый сайт

1. Создать новый репозиторий из этого шаблона.
2. Заполнить `site-data.mjs` проверенными данными мастера.
3. Загрузить изображения по структуре выше.
4. Для обычного прайса поставить `serviceMode: "simple"`.
5. Для нескольких самостоятельных направлений поставить `serviceMode: "categories"` и заполнить `serviceCategories`.
6. Если акций нет — оставить `promotions: []`.
7. Включить GitHub Pages через GitHub Actions.
8. Проверить desktop, laptop и mobile до подключения домена.

## Правило

Новый клиент не является поводом менять дизайн шаблона. Если обнаружена системная проблема, она исправляется здесь отдельным изменением и только после проверки переносится в следующие сайты.
